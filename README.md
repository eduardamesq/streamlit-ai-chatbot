# ChatBot com Inteligência Artificial

Projeto de aplicação interativa desenvolvido em Python utilizando Streamlit e integração com a API da OpenAI.

## Funcionalidades
- Interface de chat interativa
- Envio de mensagens em tempo real
- Respostas geradas por Inteligência Artificial
- Histórico de conversas utilizando session state
- Integração com modelo GPT da OpenAI

## Tecnologias utilizadas
- Python
- Streamlit
- OpenAI API

## Conceitos aplicados
- IA Generativa
- Integração com APIs
- Desenvolvimento de aplicações web
- Gerenciamento de estado
- Frontend e Backend com Python

## Objetivo
Criar uma aplicação de chatbot inteligente capaz de responder mensagens de forma dinâmica utilizando modelos de linguagem da OpenAI.
